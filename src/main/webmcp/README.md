# WebMCP generator boundary

Reserved for future inspection of a local project or website, generation of one useful capability, permission-gated installation, and independent browser verification.

No generation, installation, registration, or invocation is implemented. WebMCP is a browser capability proposal, not interchangeable with server-side MCP. Verify the current [official proposal](https://github.com/webmachinelearning/webmcp) and browser support before implementation; this foundation does not enable experimental Chromium flags.
